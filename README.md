Graham's distinct partial sums conjecture: a width sufficient condition (rigorous partial result), with proof, paper, and exact-arithmetic verification

## Features

- Clean, modern Python 3.10+ implementation.
- Typed signatures and robust error handling.
- Comprehensive unit test coverage.

## Installation & Usage

```bash
git clone https://github.com/rajveersinh-is-dev/graham-distinct-partial-sums.git
cd graham-distinct-partial-sums
python "src/graham_integer.py" --help
```
